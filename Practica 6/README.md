# Practica 6
Multiplicacion de Matrices con el método de Strassen, Strassen-Winograd y tradicional 

REQUERIMIENTOS

Implementar en el lenguaje de programación
de su preferencia el algoritmo para resolver la
multiplicación de matrices con el paradigma
de Divide y Vencerás, aplicando el algoritmo
del método Strassen.

Para realizar la multiplicación de matrices con el método
Strassen, se deben de cubrir los siguientes criterios:

❖ Solicitar al usuario el tamaño de la entrada, el cual debe de ser una
potencia exacta de 2.

❖ Inicializar las matrices a multiplicar A y B con valores aleatorios
entre 0 y 2.

❖ Realizar la multiplicación de matrices con el algoritmo de Strassen.

❖ Mostrar en pantalla las matrices A y B y la matriz de resultado C,
solo cuando el tamaño de las matrices sea menor o igual a 32 x 32.
