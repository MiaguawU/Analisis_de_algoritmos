El reporte de práctica debe incluir:
    - Portada
    - Introducción (Teoría general y básica acerca
        del tema de la práctica – Máximo 1 cuartilla).
    - Desarrollo (Algoritmo, complejidad del
        algoritmo, definir cómo se esta solucionando
        el problema, cuestiones técnicas a resaltar en
        el programa, etc).
    - Resultados (Varias pantallas de ejecución con
        una breve descripción de lo que se muestra
        en cada pantalla).
